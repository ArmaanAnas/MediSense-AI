# AI-Powered Healthcare Diagnosis Assistant

An AI-powered healthcare web application developed using Flask, MySQL, and Machine Learning to help users monitor health conditions, predict disease risks, and generate personalized health reports.

## Features

- User Authentication System
- Health Profile Management
- BMI Calculation
- Health Risk Assessment
- Diabetes Prediction
- Heart Disease Prediction
- Prediction History Tracking
- AI-Based Health Recommendations
- PDF Health Report Generation
- AI Health Assistant Chatbot

## Technology Stack

### Frontend

- Bootstrap

### Backend
- Python
- Flask

### Database

## Installation

```bash
git clone <repository-url>
cd MediSense-AI

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt

python run.py
```
